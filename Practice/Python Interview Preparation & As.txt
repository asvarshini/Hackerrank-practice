# 1. Python Data Types

### Question

```python
x = 10
y = "10"
z = 10.0

print(x + z)
print(x + y)
```

### Answer

* `x` → `int`
* `y` → `str`
* `z` → `float`

Output:

```text
20.0
TypeError
```

### Explanation

`int` and `float` can be added together, so `10 + 10.0` gives `20.0`.

A number and a string cannot be added directly, so `x + y` produces a `TypeError`.

# 19. Inheritance

# 23. Mutable Default Argument

```python
def add_item(item, items=[]):
    items.append(item)
    return items


print(add_item("A"))
print(add_item("B"))
print(add_item("C"))
```

### Output

```text
['A']
['A', 'B']
['A', 'B', 'C']
```

### Explanation

The default list is created only once, when the function is defined.

Therefore, the same list is reused across function calls.

A safer approach is:

```python
def add_item(item, items=None):

    if items is None:
        items = []

    items.append(item)

    return items
```

# 26. Shallow Copy

```python
numbers = [[1, 2], [3, 4]]

copy_numbers = numbers.copy()

copy_numbers[0].append(99)

print(numbers)
print(copy_numbers)
```

### Output

```text
[[1, 2, 99], [3, 4]]
[[1, 2, 99], [3, 4]]
```

### Explanation

`.copy()` creates a **shallow copy**.

The outer list is copied, but the nested lists are still shared.

For a completely independent nested copy, we can use:

```python
import copy

copy_numbers = copy.deepcopy(numbers)
```

# 36. Mutation Inside a Function

```python

    lst.append(4)

print(numbers)
```

### Output

```text

```

### Explanation

Lists are mutable.

The parameter `lst` refers to the same list object as `numbers`.

Therefore:

```python

```

modifies the existing list.

---

# 37. Reassignment Inside a Function

```python
numbers = [1, 2, 3]

def change(lst):

    lst = [10, 20, 30]


change(numbers)

print(numbers)
```

### Output

```text
[1, 2, 3]
```

### Explanation

Here, `lst` is reassigned to a completely new list.

The original `numbers` variable still refers to the original list.

### Important Difference

```text
Mutation → changes the existing object

Reassignment → makes the variable refer to another object
```

# 41. Second Largest Distinct Number

```python
numbers = [10, 5, 20, 8, 20, 15]

largest = None
second_largest = None

for num in numbers:

    if largest is None or num > largest:

        second_largest = largest
        largest = num

    elif num != largest and (
        second_largest is None or num > second_largest
    ):

        second_largest = num


print(second_largest)
```

### Output

```text
15
```

### Explanation

Two variables are maintained:

```text
largest
second_largest
```

When a new largest number is found, the previous largest becomes the second largest.

The condition:

```python
num != largest
```

ensures that duplicate values are not treated as a separate distinct number.

# 42. Palindrome Check Without [::-1]

```python
word = "madam"

reverse = ""

for i in range(len(word) - 1, -1, -1):

    reverse = reverse + word[i]


if word == reverse:

    print("palindrome")
```

### Output

```text
palindrome
```

### Explanation

The loop starts from the last index and moves toward the first index.

It builds the reversed string.

Then the original string is compared with the reversed string.

If both are equal, the string is a palindrome.

# 43. Debugging Index vs Value

Incorrect code:

```python
numbers = [10, 20, 30, 40]

for i in range(len(numbers)):

    if numbers[i] > 25:

        print(i)
```

This prints:

```text
2
3
```

because `i` is the index.

### Correct Code

```python
numbers = [10, 20, 30, 40]

for i in range(len(numbers)):

    if numbers[i] > 25:

        print(numbers[i])
```

### Output

```text
30
40
```

### Important Difference

```text
i           → index
numbers[i]  → value
```

# 44. Default Function Parameters

```python
def calculate(a, b=10):

    return a + b


print(calculate(5))
print(calculate(5, 20))
```

### Output

```text
15
25
```

### Explanation

`b=10` is a **default parameter**.

When only one argument is provided:

```python
calculate(5)
```

`b` uses the default value `10`.

When two arguments are provided:

```python
calculate(5, 20)
```

the supplied value `20` replaces the default value.
